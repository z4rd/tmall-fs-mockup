## 1. 搜索框 placeholder 轮换

原站搜索框的 placeholder 会定时换词，**1 帧硬切、无任何过渡动画**（tmallref2 逐帧实测）。

### 1.1 轮换间隔 —— 存在分歧，待定

| 来源 | 间隔 |
|---|---|
| 用户口述 | 3s |
| `tmallref2.mp4` 逐帧实测 | ≈5.3s |

**当前实现取 3s（按用户指示）**，但实测值可信度更高。待用户最终确认。

已收敛为单一常量 `KEYWORD_ROTATE_MS`（`src/data/searchKeywords.ts`），全项目无第二处，注释里写明了 3000 是指示值而非实测值，以免后人误读。

### 1.2 词库（用户提供，权威）

| 店铺 | 词库 |
|---|---|
| NIKE 官方旗舰店 | 飞马 / 空军一号 / 充2500得2580 / 斜挎包 |
| JORDAN | aj4 / 小飞人卫衣 / 充3000得3100 |
| ACG | 越野背心 / 冲锋衣 / 防水运动鞋 |
| NIKE 儿童 | 儿童拖鞋 / 儿童篮球鞋 / 爬爬服 |
| Home - Commercial（双11） | **未单独提供**，暂用主店词库（「充2500得2580」本身即促销类词）。待确认 |

注意词库**按店铺绑定**，`HomeVariant` 与店铺路由都要能取到对应的一套。

**已落地**：店铺标识为 `StoreKey`（`src/data/store.ts`）；`searchKeywords.ts` 中 `StoreId` 与其同义别名。与 `HomeVariant` / `Gender` **刻意正交** —— 主店的 men / women / commercial 三个变体都映射到 `nike`，共用一套词；ACG / JORDAN / 儿童各自独立。`HomeVariant` 日后增减变体或改名都不必动词库。路由到店铺的映射由 `storeIdFromPath()` 承担。

**溢出实测**（13 个词全部核对）：文本可用宽展开态 229、收起态 114（后者是约束面）。最长的「充2500得2580」排版宽 97，收起态仍余 17 —— **全部词都放得下，无溢出**。收起态上限约 9.5 个汉字，日后加词按此卡。`.cs-keyword` 的 `nowrap + overflow:hidden` 是兜底，超长词会被裁切而非撑破胶囊。

## 2. 头部 QA 意见

| # | 意见 | 状态 |
|---|---|---|
| 1 | 「下拉进入店铺直播间」的 icon 需与原稿一致（当前为近似实现） | ✅ **已修** —— 改用 3.216x 原稿切片，见下 |
| 2 | placeholder 轮换逻辑与词库，见 §1 | ✅ **已修** —— 见 §1.2 / §1.3 |

**第 1 条的处理**：手绘件是宽扁双弧，原稿实为**窄深双 V、上 V 半透明（α≈0.50）下 V 全白、两者部分交叠** —— 这个层次手绘做不出来，故改切片。从 3.216x 原图取精确包围盒（32×30 → 设计 9.95 × 9.33），按 `α = (亮度 − 底色) / (255 − 底色)` 提取 alpha 存为纯白 PNG，再以 `mask + currentColor` 渲染（`.cs-prompt-icon`），既保住原稿灰度层次，又让它继续随主题翻色。icon 区域像素差 <30 由 83.8% 提升到 **97.8%**，严重差异像素 8.1% → 0.2%。

**为什么不需要深浅两套**：提示行 `opacity = 1 − collapse × 1.6`，在 `collapse = 0.625` 即 **scrollTop ≈ 43.75** 时就归零，而底色要到 `BG_SWITCH = 140` 才翻白 —— icon 的整个可见生命周期都在深色渐变上，裕度 3 倍以上，即便 `BG_SWITCH` 取区间下限 120 也不受影响。保留 `currentColor` 只为防这个结论日后被改动时静默失效。

**顺带校正的字体差**：原稿用 iOS PingFang SC，本项目用 Noto Sans SC，同样 9 个字排出来宽 110.27 而非 106.03；整行居中，这 4.24 的超出会把 icon 一并往左带 2.1px。按 9 字摊掉差值（`letter-spacing: -0.471px`）后 icon 与文字同时归位，icon 左缘误差 0.02px、上缘 0.01px、文字宽完全一致。

关于第 1 条的范围提醒：「下拉进入店铺直播间」这个**交互**已由用户确认移出范围、不还原；但 expanded 态那行提示文案与 icon 仍需还原为**静态视觉**。本条只涉及 icon 的视觉保真度。

## 3. 保真分层决策

| 页面 | 分层 | 依据 |
|---|---|---|
| **Home - Commercial** | **Tier C（整页切图，无可点元素）** | 用户明确决定（2026-09-21） |
